# JavaScript Directory

This directory contains JavaScript files.

## Usage

```html
<script src="https://cdn.jsdelivr.net/gh/FutureAIGuide/cdn-assets@main/js/your-file.js"></script>
```

## Guidelines

- Minify JavaScript files for production
- Use meaningful file names
- Include version numbers for cache management
- Document any dependencies or requirements
- Consider using ES modules when appropriate

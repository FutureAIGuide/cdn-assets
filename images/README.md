# Images Directory

This directory contains image assets (PNG, JPG, SVG, GIF, etc.).

## Usage

```html
<img src="https://cdn.jsdelivr.net/gh/FutureAIGuide/cdn-assets@main/images/your-image.png" alt="Description">
```

## Guidelines

- Optimize images before uploading (compress, resize)
- Use appropriate formats (SVG for logos, PNG for transparency, JPG for photos)
- Use descriptive file names
- Keep file sizes reasonable (prefer <1MB per image)
- Consider providing multiple resolutions for responsive designs
